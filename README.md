# DICOM Viewer

A private, in-browser DICOM/MRI viewer. Built on [dwv-simplistic](https://github.com/ivmartel/dwv-simplistic) (DICOM Web Viewer).

Everything runs client-side in your browser — dragging a DICOM folder or files onto the page reads and renders them locally via JavaScript. **Nothing is uploaded to any server.** This repo only hosts the viewer code, not any imaging data.

Not for diagnostic or clinical use.

## Usage

Open the GitHub Pages link, then drag your DICOM folder (or files) onto the viewer, or use the toolbar's open-file button.
